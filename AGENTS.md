# AGENTS.md

## Regra obrigatória

Toda alteração feita neste repositório **DEVE** ser commitada e enviada ao GitHub (push) imediatamente após a modificação.

### Procedimento

1. Após qualquer alteração de arquivo, executar:
   ```
   git add -A
   git commit -m "descrição da alteração"
   git push
   ```
2. Nunca deixar alterações pendentes sem commit.
3. Cada commit deve conter uma mensagem descritiva e clara da mudança realizada.
